# Лабораторная работа №6. Введение в Node.js и базовый сервер на Express

# Задание

- Инициализировать проект (`npm init`), установить Express.
- Создать сервер, который отдаёт статические файлы (HTML, CSS, JS).
- Реализовать несколько маршрутов: `/` (главная), `/about` (о себе), `/api/status` (JSON ответ).
- Научиться работать с параметрами запроса и query-параметрами.
- Добавить манифест (**manifest.json**) с иконками и подключить его в HTML.
- Реализовать **service worker**: кешировать статику и обеспечить работу приложения офлайн, зарегистрировать его на странице.

**Вариант 14. Тема «Генератор цитат» (случайная цитата)** Маршруты: `GET /`, `GET /about`, `GET /api/quote`. Логика: массив цитат (text, author). `Query ?lang=en` фильтрует английские цитаты. Без параметров – случайная из всех. Ответ: `{ text: "...", author: "...", lang: "ru" }`. Ошибки: если цитат нет – `500 + { error: "No quotes available" }`.

# Результат

- Проект инициализирован, зависимости установлены.
- Сервер запускается, все маршруты работают.
- Статика отдаётся корректно.
- Параметры запроса обрабатываются.
- Манифест подключён, приложение устанавливается.
- Service worker зарегистрирован, приложение работает офлайн.
